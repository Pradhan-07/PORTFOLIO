Most student portfolios fall into two categories: the generic Bootstrap template that everyone copies, or an over-engineered site that never actually gets deployed.

I wanted something different for this site:
- Strictly monochrome: letting structure, physics, and typography carry the weight without neon distraction colors.
- Built from first principles: 2D Verlet integration physics for the interactive lanyard rather than dragging in heavy Three.js dependencies.
- Radical honesty: showing what is built, what is in progress, and exact GitHub commit logs without inflating titles.

Being a beginner isn't something to hide behind buzzwords. Showing up every day, documenting bugs, and shipping code is the actual differentiator.
